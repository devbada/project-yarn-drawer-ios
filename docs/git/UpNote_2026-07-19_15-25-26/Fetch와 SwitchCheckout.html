Fetch와 Switch/Checkout

작업
설명
Fetch
 생성된 Branch와 변경된 서버의 정보를 가져옵니다.
Switch / Checkout
 현재 작업공간(Branch)에서 다른 Branch(작업공간)로 변경합니다.
 
  1. Fetch 하기
    • 요약
      • "Branch 생성하기" 매뉴얼에서 만든 새로운 Branch 정보를 받아오고 확인해 봅니다.
    • 현재 작업공간에서 Branch 확인하기
      • 프로젝트(=소스)가 위치한 곳에서 마우스 오른쪽을 클릭하여 현재 Branch 를 확인합니다.
  • 현재 작업 공간은 "master" Branch 인 것을 확인할 수 있습니다.
    • 참고: 처음 프로젝트를 Clone 하면 master (혹은 기본 Branch) 로 지정됩니다.
  • 새로운 Branch, 그리고 변경된 저장소 정보 받기 (=fetch)
    • 새로운 Branch는 서버에서만 생성되어 있습니다. 따라서 현재 작업공간(Local Branch)에서는 그 정보를 알 수 없습니다.
    • 이 정보를 알기 위해 fetch 라는 명령어를 사용하거나 TortoiseGit 툴을 사용하여 fetch 할 수 있습니다.
    • 작업영역의 빈 공간에서 마우스 오른쪽 클릭 > TortoiseGit > Fetch …
 
  • 1
    가져올 위치를 선정합니다.
    특별한 경우가 없다면 orgin (원본위치) 으로 선택하면 됩니다.
 
  • Fetch 결과를 보여줍니다. 위의 빨간박스 내용을 보면 new branch 라고 표기되어 있으며, 서버에서 새로운 branch 정보를 받아왔음을 보여줍니다.
  1. switch / checkout 하기
    • 새로운(=다른) Branch 로 변경하기 위해 switch/checkout 할 수 있습니다.
      • switch
        		 다른 Branch로의 전환을 뜻합니다. 이미 Local에 지정된 branch로 변경할 경우 switch 함을 의미합니다.
        checkout
        		 branch의 데이터를 가져옵니다. Local에 선택한 branch 가 없을 경우 checkout 하고 switch 하게 됩니다.
 
  • 작업영역에서 마우스 오른쪽 클릭 > TortoiseGit > Switch/Checkout 합니다.
 
  • 1
    		 Switch/Checkout 대상 Branch를 선택할 수 있습니다.
    2
    		 Local 에 Branch가 없고 선택한 Branch의 위치가 remotes / ..  인 경우 자동 선택됩니다.
  • OK 버튼을 클릭하면 새로운 Branch로 switch/checkout 됩니다.
  • 참고: 빨간 박스의 내용을 잘 확인하세요.
  • 실제 사용된 명령어를 함께 확인할 수 있습니다.
    • git.exe checkout -b SR- …
  • 이제 변경된 정보를 확인할 수 있습니다.
